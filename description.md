Название проекта
«Исследование факторов, влияющих на успешность студента в вузе»

Файлы проекта
- `intellectual-reactor.ipynb` — Jupyter Notebook с исходным кодом и результатами исследования.
- `description.md` — описание проекта.

Используемые библиотеки языка Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

Цель проекта

Исследование факторов, связанных с успешностью обучения студентов и их отчислением, а также выявление признаков, которые наиболее тесно связаны с результатом обучения.

Описание проекта

В проекте проводится анализ набора данных о студентах. В качестве результата обучения рассматриваются две категории: `Graduate` — успешное завершение обучения и `Dropout` — отчисление.
Для исследования используются разнообразные характеристики студентов, например, показатели их учебной деятельности, социальные и семейные факторы, а также экономические показатели региона.
Основная часть исследования выполнена в Jupyter Notebook с использованием языка программирования Python.

Этапы исследования

1. Подготовка данных
В начале работы выполняется загрузка набора данных с помощью библиотеки Pandas. Проводится первичный анализ структуры набора данных и его признаков.
Из исходных данных выделяются записи, относящиеся к двум рассматриваемым результатам обучения: `Graduate` и `Dropout`.

2. Анализ социально-демографических факторов
   
- полом
- семейным положением
- курсом обучения
- способом подачи заявления
- порядком подачи заявления
- возрастом на момент поступления
- наличием стипендии
- наличием задолженности
- своевременностью оплаты обучения
Исследуется связь результата обучения с различными характеристиками студентов.
Для различных групп студентов строятся таблицы и графики, позволяющие сравнивать доли успешно завершивших обучение и отчислившихся студентов.

3. Анализ учебных показателей

Исследуются показатели учебной деятельности студентов за первый и второй семестры.
Рассматриваются:
- количество записанных дисциплин
- количество дисциплин, по которым проводилась оценка
- количество зачтённых дисциплин
- количество успешно завершённых дисциплин
- средние оценки
- количество дисциплин без оценок
Проводится сравнение данных показателей для студентов, завершивших обучение, и студентов, которые были отчислены.

4. Анализ семейных факторов
   
Исследуется связь результата обучения с характеристиками родителей, в том числе:
- уровнем образования матери
- уровнем образования отца
- профессией матери
- профессией отца

5. Анализ экономических факторов

Рассматривается влияние экономических показателей региона на результат обучения студентов.
Исследуются:
- уровень безработицы
- уровень инфляции
- ВВП региона
Для этих показателей строятся распределения и выполняется сравнение групп `Graduate` и `Dropout`.

6. Корреляционный анализ

Для различных групп признаков строятся корреляционные матрицы.
Отдельно рассматриваются:
- экономические факторы
- показатели учебной деятельности
- семейные факторы
- социальные факторы
Корреляционный анализ позволяет определить наличие и степень связи между признаками и результатом обучения.

7. Построение моделей

Для оценки связи выбранных признаков с результатом обучения используются модели линейной регрессии.

Рассматриваются несколько наборов признаков:
1. пол студента
2. пол и основные учебные показатели
3. набор учебных и социальных показателей

Для построения моделей данные разделяются на обучающую и тестовую выборки.

8. Оценка моделей

Качество построенных моделей оценивается с использованием следующих метрик:
- MAE — средняя абсолютная ошибка;
- MSE — средняя квадратичная ошибка;
- R² — коэффициент детерминации.
Также анализируются коэффициенты полученных моделей и их свободные члены.

Результат проекта

В результате работы проведено исследование факторов, связанных с успешностью обучения и отчислением студентов.
Выполнен анализ социально-демографических, учебных, семейных и экономических показателей, построены визуализации и корреляционные матрицы.
Также построены и сравнены модели линейной регрессии с различными наборами признаков. Для каждой модели рассчитаны показатели качества на обучающей и тестовой выборках.
